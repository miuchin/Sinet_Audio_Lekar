🎛 SINET Control Center + Install

Control Center je odvojen od Audio Lekara. Po planu služi za instalacije za korisnika, desktop launcher, lokalni start, backup i GitHub/Netlify tokove.

Zato ga ne vidiš kao terapijski ekran unutar aplikacije. U Audio Lekaru postoji dokumentacioni ulaz, a sam alat je u folderu tools/control-center/.

Otvori Control Center vodičREADME

Brza instalacija na Manjaru

chmod +x tools/control-center/*.sh
chmod +x tools/control-center/*.desktop
./tools/control-center/install_sinet_control_center.sh

Installer pravi ~/Desktop/SINET_Control_Center i kopira sve potrebne fajlove.
