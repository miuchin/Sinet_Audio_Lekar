🗂 Zdravstveni Karton — protokol (SR)

Šta je ovo? Zdravstveni Karton je centralna evidencija nalaza, terapija i događaja. Kada ga koristiš? Posle unosa anamneze i bar jednog Lab Snapshot-a. Šta dalje? Ovde pratiš istoriju, trendove, specijalističke sažetke i poređenja kroz vreme.

Svrha: centralna evidencija: laboratorije, događaji, terapije, trend/compare, specijalistički sažeci, prilozi.

1) Prvi start (minimum)

  1. Napravi 1 Lab Snapshot u LAB Bridge.
  2. Uđi u Karton → proveri broj snapshot-a.
  3. Postavi Default Analyses.

2) Default Analyses

  • Unesi listu analiza koje pratiš kroz vreme (KKS, Glukoza, Insulin, HOMA‑IR…).

3) Lab Snapshots

  • Pregled istorije, izbor baseline, export/copy JSON.

4) Compare A/B/C/D

  1. Snapshot A = baseline
  2. B/C/D = poređenja
  3. „Uporedi/Osveži“

5) Trendovi

  • Ako postoje numeričke vrednosti: ↗/↘/→ trend po parametrima.

6) Specialist views

  • Generiši sažetak za specijalistu
  • Kopiraj specialist JSON
  • Kopiraj prompt pack
  • Export u HTML (print)

7) Terapije

  • Lek/doza/učestalost/period/napomena; preporuka: vezuj uz događaj ili nalaz.

8) Medicinski događaji

  • Datum + opis + napomena; može imati priloge.

9) Attachments

  • Vezani uz događaj ili terapiju; veliki fajlovi idu metadata‑only.
