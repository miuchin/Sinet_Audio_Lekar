🎛 SINET Control Center v1

Control Center je spoljašnji alat, zamišljen da bude van Audio Lekar aplikacije. Njegov posao nije terapijski UI, nego administracija projekta: instalacija za korisnika, desktop launcher, lokalni start, backup, GitHub/Netlify i centralni panel za više projekata.

📄 README 🛠 install_sinet_control_center.sh 🧩 projects.json

Šta dobijaš

  • Centralni meni za više projekata — SINET Audio Lekar + Paprikas Hub.
  • Install / launcher — desktop ikona i brzi start na Manjaru.
  • Project config preko projects.json.
  • Backup, Git init/publish, otvaranje GitHub i Netlify linkova.

Ovo je administrativni sloj i zato je namerno odvojen od glavnog Audio Lekar UI-a.

Brza instalacija na Manjaru

  1. Raspakuj projekat.
  2. Otvori folder tools/control-center/.
  3. Pokreni:
chmod +x tools/control-center/*.sh
chmod +x tools/control-center/*.desktop
./tools/control-center/install_sinet_control_center.sh

Skripta pravi folder ~/Desktop/SINET_Control_Center i kopira potrebne fajlove za rad.

Fajlovi

  • sinet_control_center_manjaro.sh — glavni panel
  • sinet_control_center.desktop — desktop launcher
  • install_sinet_control_center.sh — brza instalacija
  • projects.json — konfiguracija projekata
  • *github*_manjaro.sh — legacy GitHub skripte
