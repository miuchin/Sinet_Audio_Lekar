🎓 Tutor / Vodiči (indeks)

Ovo je centralno mesto za praktične tutor stranice (use-case protokole). Cilj je da korisnik za 1 minut odluči koji vodič mu treba, a zatim prati korake bez nagađanja.

Kako koristiti ovu stranicu:

  • Ako želiš samo da pustiš zvuk → otvori **Quick Start (3 klika)**.
  • Ako želiš da sačuvaš svoje liste → otvori **Backup / Restore**.
  • Ako praviš rutinu (40 min × N dana) → otvori **Moj protokol iz Queue**.
  • Ako radiš katalog/diagnostiku → otvori **MKB Linker → dx_index → Anamneza**.
  • Ako koristiš AI pomoć za unos → otvori **AI Upitnik → Moji simptomi → Queue → Protokol**.

⏱ 1-min decision tree (gde da idem?)

  • **Treba mi samo reprodukcija odmah (bez podešavanja)**
  • ➜ Quick Start — 3 klika do reprodukcije
  • **Menjao sam telefon / browser ili hoću rezervu podataka**
  • ➜ Tutor #1 — Backup / Restore
  • **Sastavio sam listu i hoću da je pretvorim u rutinu/protokol**
  • ➜ Tutor #2 — Moj protokol iz Queue (40 min × N dana)
  • **Radim medicinski tok (MKB mapiranje → indeks → Anamneza)**
  • ➜ Tutor #3 — MKB Linker → dx_index → Anamneza
  • **Hoću da AI predloži stavke pa da ih pretvorim u protokol**
  • ➜ Tutor #4 — AI Upitnik → Moji simptomi → Queue → Protokol

📚 Preporučeni redosled za nove korisnike (stariji korisnici / početnici)

  1. Quick Start — 3 klika
  2. Backup / Restore
  3. Moj protokol iz Queue
  4. AI Upitnik → Protokol
