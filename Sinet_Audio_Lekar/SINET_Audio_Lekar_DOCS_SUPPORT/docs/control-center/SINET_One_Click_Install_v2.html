Krajnji korisnik ne treba da razmišlja o terminalu, komandama, chmod koracima ili putanjama.

1 dugmeautomatska instalacijadesktop prečicalokalni startbez CMD koraka

Kako izgleda korisnički tok

  1. Raspakuje ZIP paket.
  2. Dvoklikne na INSTALL SINET Audio Lekar.
  3. Skripta sama instalira aplikaciju, pravi prečice, dodaje Safe Mode i otvara aplikaciju.

Zašto postoji Safe Mode

  • meni se ne otvara,
  • brzi linkovi nisu potpuni,
  • stara verzija i dalje iskače iako je ZIP zamenjen.
Safe Mode otvara index-nosw.html i služi za brz oporavak bez tehničke intervencije.

Administrativni i korisnički sloj

  • Korisnik: jedno dugme INSTALL SINET Audio Lekar.
  • Admin: po potrebi koristi SINET Control Center.
